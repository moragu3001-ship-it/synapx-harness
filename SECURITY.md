# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x Public Alpha | Yes |

## Reporting a vulnerability

Do not disclose sensitive vulnerabilities through public Issues,
Discussions, or PRs.

Use **GitHub Private Vulnerability Reporting** on the repository to
report a sensitive vulnerability privately.

Please include where applicable:

- Affected version
- Environment
- Python version
- Provider / agent information where relevant
- Reproduction
- Expected result
- Actual result
- Security impact
- Relevant redacted logs / evidence

Redact secrets, credentials, tokens, and any non-public personal
data before submitting.
